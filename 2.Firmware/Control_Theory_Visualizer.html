🧠 自动控制原理核心目标

控制系统的四大性能指标：

  • 稳定性 (Stability)：系统能够回到平衡状态
  • 快速性 (Rapidity)：系统响应速度要快
  • 准确性 (Accuracy)：稳态误差要小
  • 鲁棒性 (Robustness)：对扰动和参数变化不敏感

🧮 核心数学工具

1. 拉普拉斯变换

L[f(t)] = F(s) = ∫₀^∞ f(t)e^(-st)dt

作用：将时域微分方程转换为频域代数方程

2. 传递函数

G(s) = Y(s)/U(s) = (b_n s^n + ... + b_1 s + b_0)/(a_m s^m + ... + a_1 s + a_0)

作用：描述系统输入输出关系，零初始条件下的动态特性

3. 闭环传递函数

T(s) = Y(s)/R(s) = G_c(s)G(s)/(1 + G_c(s)G(s)H(s))

作用：描述闭环系统的整体传递特性

⚙️ 典型系统建模

一阶系统

G(s) = K/(Ts + 1)

其中：K - 增益，T - 时间常数

二阶系统

G(s) = ωₙ²/(s² + 2ζωₙs + ωₙ²)

其中：ωₙ - 自然频率，ζ - 阻尼比

⚖️ 稳定性判据

极点位置判据

稳定：所有极点实部 < 0

临界稳定：有极点在虚轴上

不稳定：有极点实部 > 0

Routh-Hurwitz判据

特征方程：1 + G(s)H(s) = 0

Routh表：系数按特定规律排列

稳定条件：第一列系数全为正
